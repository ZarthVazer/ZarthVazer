## How I Work

- **Everything as code** — infrastructure, configuration and pipelines live in Git and go through review
- **Automate the second time** — if a task is done twice, it gets a script or a pipeline
- **Secure by default** — non-root containers, scanned images, no secrets in code
- **You can't fix what you can't see** — every service ships with health checks, metrics and logs
